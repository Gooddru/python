# Лабораторная работа 3

Подготовка данных Stack Overflow для поиска по вопросам и ответам.

## Что изучается

- объединение вопросов, ответов и тегов;
- очистка HTML, Markdown и программного кода;
- обработка текста и токенизация;
- построение базового индекса для поиска.

[Открыть ноутбук](notebooks/lab-03.ipynb)

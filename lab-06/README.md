# Лабораторная работа 6

RAG-система для Stack Overflow: семантический поиск и генерация ответа Gemini.

## Что изучается

- подключение к сохранённой коллекции ChromaDB;
- поиск релевантных вопросов и ответов;
- формирование контекста и промпта;
- генерация ответа языковой моделью.

## Решение

[Открыть ноутбук](notebooks/lab-06.ipynb)

Для запуска нужны база `chroma_db`, файл `api.txt` с API-ключом и библиотеки ChromaDB, Sentence Transformers и Google Generative AI. Секретный ключ не добавляется в репозиторий.
